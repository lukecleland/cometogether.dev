# Product wording

The product is **Make Together** (domain: `maketogether.dev`). Use this name in user-facing copy and new features. Music collaboration should say **Make Music Together**. Keep the stylized `maketogether` wordmark where it is part of the visual brand.

Legacy `watchtogether` persistence keys, bundle identifiers and peer-message fields are compatibility contracts; do not rename them as part of copy changes.

# Live delivery workflow

The user works against the live deployment, not a local development preview. For every requested change in this project, finish the relevant checks and then complete the `push-it` workflow: commit, push, create or update the pull request, and merge when permitted. Do not stop at “not pushed yet” or wait for a separate push request. Verify the production deployment when publishing and report its actual status. Preserve unrelated work and follow the existing rules for checks and review overrides.
